## 核心哲学

> 定投的本质是低位多买。不因价格下跌止损，不因短期研判砍长期配置。
> 估值决定定投流向，纪律决定止盈止损。全股权益——人生要搏。

5. 不买新主动基金——被动ETF联接是长期定投唯一选择
