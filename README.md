# 基金定投投资项目框架

**版本**：Plan F v3（2026-07-30确立） | **策略**：红利低波+科技哑铃 | **周期**：10-20年 | **投入**：¥920/日 × 250交易日 = ¥230,000/年

## 核心哲学

> 定投的本质是低位多买。不因价格下跌止损，不因短期研判砍长期配置。估值决定定投流向，纪律决定止盈止损。

| 层 | 持有周期 | 基金 | 策略 |

## 永远不做的5件事

1. 不因价格下跌割肉 — 检查基本面止损条件，未触发就继续定投
2. 不因短期研判砍长期配置 — 分析师看6-12月，我们看10-20年
3. 不追高加仓 — PE分位>80%的基金不追加定投
4. 不全压单一赛道 — 科技三足鼎立（恒科+创新药+双创）
5. 不买新主动基金 — 被动ETF联接是长期定投唯一选择
